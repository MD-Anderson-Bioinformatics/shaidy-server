NGCHM Web Service

This is the home page for the NGCHM web service. This web service provides resources for storing and serving Next-Generation Clustered Heat Maps (NG-CHM) and collections thereof. It is not intended to be used directly for managing and/or browsing NG-CHMs and so does not include a web-based user interface for those activities. Tools for managing / browsing NG-CHMs stored on this system include:

  • The NGCHM Manager is a web-based system for managing and browsing collections of NG-CHMs.
  • The NGCHMR R package is a system for managing NG-CHMs from the R statistical environment (including by scripts).
  • The NGCHM Compendium Viewer is a web-based system for browsing a graphical compendium of NG-CHMs.
